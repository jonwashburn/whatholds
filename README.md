# whatholds.com

The public page for **Holdfast**, memory for long projects.

One static file, `index.html`. No build step, no JavaScript, no dependencies beyond a
webfont link. Served by GitHub Pages at [whatholds.com](https://whatholds.com/).

Every number on the page is computed from the store it describes, on the date printed
next to it. If a number changes, the date changes with it.

Holdfast itself is not in this repository.
